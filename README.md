# Kadra

Десктопная оболочка над **ffmpeg / ffprobe** и **yt-dlp** в стиле Material Design 3.
Цель — открыть практически все возможности ffmpeg без командной строки: быстро и понятно
для новичка, с полным контролем для эксперта.

Платформы: **Windows 10/11** (основная), **Linux**. Стек: Flutter + Dart, Riverpod, drift (SQLite),
media_kit (libmpv), локализация через ARB (русский — основной, английский).

> Рабочее название «Kadra» (от «кадр») — легко поменять.

## Статус

**Этап 1 — каркас и ядро** (готов): тема MD3, навигация, движок команд ffmpeg с прогрессом,
очередь (SQLite), менеджер компонентов (ffmpeg/yt-dlp/Deno/aria2c, SHA-256, откат),
аппаратное ускорение, анализ файла, настройки с подсказками.

**Этап 2 — MVP-инструменты** (готов):

- **Конвертация и сжатие**: MP4/MKV/MOV/WebM/AVI/TS и аудиоформаты; H.264/H.265/AV1/VP9
  (программно и на видеокарте: NVENC, QSV, AMF, VAAPI), ProRes, DNxHR, FFV1, MJPEG, копирование;
  режимы «Качество» (CRF/CQ), битрейт, постоянный битрейт, **размер файла** (расчёт битрейта,
  два прохода); скорость, разрешение, FPS, 10 бит, профиль, tune, ключевые кадры; проверка
  совместимости кодека и контейнера.
- **Пресеты**: Telegram, YouTube, Discord (до 10 МБ), монтаж ProRes/DNxHR, архив без потерь,
  максимальное сжатие, «просто сжать» + свои пресеты с импортом/экспортом JSON.
- **Обрезка**: быстрая без перекодирования (показывает реальный ключевой кадр начала) и точная до кадра.
- **Звук**: извлечь (как есть или в MP3/AAC/Opus/FLAC/WAV), заменить, добавить дорожку, удалить.
- **Нормализация громкости**: двухпроходная loudnorm (−14 / −16 / −23 LUFS), видео копируется.
- **GIF / WebP / APNG** с генерацией палитры.
- **Загрузки yt-dlp**: несколько ссылок, плейлисты с выбором элементов, качество/формат,
  субтитры, обложка и метаданные, SponsorBlock, cookies из браузера, архив скачанного.
- Многошаговые задачи в очереди (двухпроходное кодирование, измерение → применение).
- «Показать команду» у каждого инструмента; опционально — правка команды перед запуском.

**Этап 3 — монтаж, звук, анализ** (готов):

- **Аудиоредактор в духе Audacity**: многодорожечная правка до сэмпла, отмена/повтор,
  метки, огибающая громкости, 54 эффекта (динамика, эквалайзеры, шумоподавление с профилем,
  тон/темп, эхо/реверберация, модуляция…), генераторы (тон, шум, DTMF, метроном), анализ
  (статистика, спектр, поиск тишины/долей/перегрузки), запись с микрофона, экспорт по меткам.
- **Монтаж видео**: вырезка фрагментов (точно или без перекодирования), склейка (без
  перекодирования или с приведением к одному кадру), переходы xfade и появление/исчезание,
  разделение (по времени, на части, по главам, по точкам), кадрирование с поиском чёрных полей,
  поворот/отражение/наклон, смена пропорций (поля, заполнение, размытый фон — вертикальные
  видео), скорость и реверс (с сохранением тона или без, плавное замедление), восстановление
  (деинтерлейс, шумоподавление, резкость, стабилизация vidstab в два прохода), цвет (яркость,
  контраст, насыщенность, гамма, оттенок, температура, стили, виньетка, LUT с силой),
  логотип/текст/таймкод с окном времени, размытие/пикселизация/delogo областей, сетка
  и «картинка в картинке», повтор и бумеранг, HDR → SDR (zscale + tonemap или libplacebo).
- **Предпросмотр кадра** с применённым фильтром: до / после / шторка; области для
  кадрирования и размытия рисуются мышью прямо на кадре.
- **A/B-сравнение**: короткий фрагмент кодируется с текущими настройками и показывается
  рядом с оригиналом (шторка, рядом, переключение) вместе с оценкой итогового размера;
  для звука — синхронное переключение «до / после».
- **Звук целых файлов**: шумоподавление (RNNoise, FFT, NLM, щелчки, фон сети), цепочки
  эффектов аудиоредактора, музыка под видео с автоприглушением под голос, распознавание речи
  (фильтр whisper, ffmpeg ≥ 8 с whisper.cpp) в SRT/текст/JSON.
- **Анализ**: громкость EBU R128 с графиком и сравнением с нормами площадок, осциллограмма
  и спектрограмма в PNG, детекторы (тишина, чёрные и застывшие кадры, смена сцен, чёрные поля)
  с передачей найденного в «Вырезать», «Разделение» и «Кадр», сравнение качества PSNR/SSIM/VMAF.
- **Модели** RNNoise и Whisper скачиваются по требованию (проверка SHA-256), управляются
  в «Компонентах».

Все фильтры и опции сверены с `ffmpeg -h filter=…` на ffmpeg 6.1 и 9.0 (whisper — по исходникам
ffmpeg 8.0, его нет в сборках BtbN); каждый граф прогоняется в интеграционных тестах.

**Этап 4 — субтитры, картинки, метаданные, ремонт** (готов):

- **Субтитры**: вшить в видео (дорожка из файла или SRT/ASS/VTT, размер, цвет, подложка,
  положение, кодировка CP1251 и др.) с предпросмотром кадра; добавить дорожки с языком,
  названием и флагами «по умолчанию»/«принудительные», удалить или извлечь (SRT/ASS/VTT,
  графические — как есть) без перекодирования; конвертация SRT ↔ ASS ↔ WebVTT со сдвигом,
  пересчётом частоты кадров (25 ↔ 23,976) и сменой кодировки.
- **Картинки**: кадры (один, лучший, через интервал, N штук, на смене сцен) в PNG/JPEG/WebP/
  AVIF/JPEG XL; раскадровка с временем на миниатюрах; слайд-шоу с переходами, плавным наездом
  и музыкой (можно подогнать под длину музыки); аудио → видео с обложкой из файла, своей
  картинкой или цветом, размытым фоном и волной; визуализаторы (волна, спектр, вектороскоп,
  ноты); конвертация изображений с ограничением размера и удалением EXIF/GPS.
- **Метаданные**: теги (в том числе свои и языки дорожек), обложка (добавить, заменить,
  удалить, сохранить), главы (редактирование, вставка и копирование списка в формате YouTube).
- **Ремонт**: пересборка с восстановлением временных меток, сдвиг звука, перекодирование
  с постоянной частотой кадров и подстройкой звука; faststart для MP4/MOV с проверкой,
  нужен ли он файлу.

Дальше: этап 5 — пакетная обработка, рецепты, наблюдение за папкой, редактор команд,
запись экрана и стриминг.

## Сборка

Нужен Flutter stable (проверено на 3.47.9).

```bash
flutter pub get
flutter test
flutter run -d windows   # или -d linux
```

Linux: нужны `libgtk-3-dev`, `libmpv-dev`, `ninja-build`, `clang`, `cmake`.
media_kit по умолчанию скачивает mimalloc с GitHub; для офлайн-сборок можно взять системный
(`libmimalloc-dev`): `KADRA_SYSTEM_MIMALLOC=1 flutter build linux`.

После изменения таблиц БД: `dart run build_runner build`. Строки интерфейса задаются в `tool/l10n/*.py` (`python3 tool/l10n/arb.py` пишет `lib/l10n/app_*.arb`)
(код генерируется в `lib/l10n/gen` при сборке или `flutter gen-l10n`).

`kadra <файл>` открывает файл сразу на главной.

## Структура

```
lib/
  core/
    engine/      построитель команд, прогресс, процессы, ошибки, возможности сборки, HW-ускорение
    probe/       ffprobe → модели (потоки, главы, HDR)
    queue/       очередь задач
    components/  источники, загрузка с SHA-256, установка, откат, выбор бинарников
    db/          drift: задачи и пресеты
    settings/    модель настроек
    platform/    ОС/архитектура, пути данных
    ytdlp/       yt-dlp: метаданные (-J), аргументы загрузки, прогресс
    presets/     пользовательские пресеты
  features/      экраны и построители команд: convert, trim, audio, gif, downloads,
                 home, tools, queue, presets, components, settings, analysis,
                 edit (графы монтажа), audio_editor (движок и интерфейс редактора)
  ui/            тема, общие виджеты (SettingTile с «?» и сбросом, ZonedSlider…)
test/            юнит-тесты построителей команд и ядра + интеграционные: каждый пресет и
                 операция прогоняются через реальный ffmpeg (KADRA_TEST_FFMPEG=<папка> —
                 проверить конкретную сборку; KADRA_TEST_RNNOISE=<модель> — RNNoise)
```

Внешние инструменты не входят в сборку: приложение скачивает их через менеджер компонентов
(так проще с лицензиями GPL-сборок ffmpeg и с обновлениями).
