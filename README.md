# Kadra

Десктопная оболочка над **ffmpeg / ffprobe** и **yt-dlp** в стиле Material Design 3.
Цель — открыть практически все возможности ffmpeg без командной строки: быстро и понятно
для новичка, с полным контролем для эксперта.

Платформы: **Windows 10/11** (основная), **Linux**. Стек: Flutter + Dart, Riverpod, drift (SQLite),
media_kit (libmpv), локализация через ARB (русский — основной, английский).

> Рабочее название «Kadra» (от «кадр») — легко поменять.

## Статус

Этап 1 из 6 — **каркас и ядро** (готов):

- тема MD3 (светлая/тёмная/системная, системный или свой акцент), навигация Rail/Bar, горячие клавиши;
- **ядро движка**: типизированный построитель команд ffmpeg, прогресс через `-progress pipe:1`
  (процент, fps, скорость, битрейт, ETA), запуск процессов с отменой и паузой (Linux),
  разбор ошибок ffmpeg/yt-dlp в понятные сообщения;
- **очередь задач**: параллелизм, приоритеты, повторы, сохранение между перезапусками (SQLite);
- **менеджер компонентов**: ffmpeg (BtbN GPL/LGPL, релиз/nightly; gyan.dev essentials/full на Windows),
  yt-dlp (stable/nightly), Deno, aria2c (Windows); проверка SHA-256, установка, обновление,
  откат и удаление версий, свой путь к бинарнику;
- возможности сборки (кодировщики, декодеры, фильтры, контейнеры) и **автоопределение
  аппаратного ускорения** пробным кодированием (NVENC, QSV, AMF, VAAPI, Vulkan);
- **главная**: drag-and-drop, превью, подробный анализ файла (ffprobe), умные быстрые действия;
- **инструменты**: каталог всех запланированных функций с поиском; доступны «Информация о файле»
  и «Проверка целостности»;
- **настройки** с подсказками, «?»-справкой, сбросом, поиском и простым/расширенным режимом.

Дальше: этап 2 — конвертация и сжатие с пресетами, обрезка, звук, нормализация, GIF, загрузки yt-dlp.

## Сборка

Нужен Flutter stable (проверено на 3.47.9).

```bash
flutter pub get
flutter test
flutter run -d windows   # или -d linux
```

Linux: нужны `libgtk-3-dev`, `libmpv-dev`, `ninja-build`, `clang`, `cmake`.
media_kit по умолчанию скачивает mimalloc с GitHub; для офлайн-сборок можно взять системный
(`libmimalloc-dev`): `KADRA_SYSTEM_MIMALLOC=1 flutter build linux`.

После изменения таблиц БД: `dart run build_runner build`. Строки интерфейса — в `lib/l10n/app_*.arb`
(код генерируется в `lib/l10n/gen` при сборке или `flutter gen-l10n`).

`kadra <файл>` открывает файл сразу на главной.

## Структура

```
lib/
  core/
    engine/      построитель команд, прогресс, процессы, ошибки, возможности сборки, HW-ускорение
    probe/       ffprobe → модели (потоки, главы, HDR)
    queue/       очередь задач
    components/  источники, загрузка с SHA-256, установка, откат, выбор бинарников
    db/          drift: задачи и пресеты
    settings/    модель настроек
    platform/    ОС/архитектура, пути данных
  features/      экраны: home, tools, downloads, queue, presets, components, settings, analysis
  ui/            тема, общие виджеты (SettingTile с «?» и сбросом, ZonedSlider…)
test/            юнит-тесты построителя команд и ядра + интеграционные с реальным ffmpeg
```

Внешние инструменты не входят в сборку: приложение скачивает их через менеджер компонентов
(так проще с лицензиями GPL-сборок ffmpeg и с обновлениями).
