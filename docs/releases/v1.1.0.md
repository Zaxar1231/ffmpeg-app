<!-- Kadra v1.1.0 -->
Доделаны оставшиеся пункты плана: плагины эффектов, шрифты, готовые цветовые образы, запись окна, подсказки в редакторе команд. Исправлена ошибка кодирования в MP3.

## Установка

- **Windows 10/11 (x64):** установщик `kadra-v1.1.0-windows-x64-setup.exe` или переносная версия `kadra-v1.1.0-windows-x64.zip`.
- **Linux (x64):** `kadra-v1.1.0-linux-x86_64.AppImage` или `kadra-v1.1.0-linux-x64.tar.gz`.

Kadra 1.0.x найдёт это обновление сама (после запуска или в Настройках → «Проверить»).

## Исправлено

- **MP3:** кодирование могло падать с ошибкой «Error encoding a frame: Cannot allocate memory», если в звуке встречались битые отсчёты (NaN) или запредельные значения. Теперь звук перед MP3-кодером переводится в 16 бит — это работает везде, где Kadra пишет MP3, включая экспорт из аудиоредактора и редактор команд.

## Новое

- **Плагины эффектов** (новый инструмент): видеоэффекты frei0r и аудиоплагины LV2, с предпросмотром кадра; описание и число параметров плагина берутся из ffmpeg. В Linux плагины ставятся пакетами `frei0r-plugins` и LV2-плагинами; в Windows DLL frei0r (с frei0r.dyne.org) кладутся в папку плагинов Kadra — кнопка «Открыть папку» на странице инструмента.
- **Шрифты** в «Компонентах»: десять свободных шрифтов с кириллицей (Noto Sans, PT Sans, PT Serif, Montserrat, Oswald, Roboto Mono, Lobster, Caveat, Rubik Mono One) с проверкой SHA-256. Выбираются для вшитых субтитров и для надписей на видео. На Windows без них ffmpeg мог не найти шрифт для надписи.
- **Цвет:** готовые образы — тёплый, холодный, кино (бирюза и оранж), выцветший, винтаж, яркий, контрастный ч/б — рядом с импортом своих LUT.
- **Запись экрана:** в Windows — быстрый захват через видеокарту (Desktop Duplication, `ddagrab`), меньше нагрузки и пропусков кадров, работает с играми; запись **одного окна** из списка открытых (Windows и Linux; в Linux нужен `wmctrl`).
- **Разделение по размеру:** части примерно заданного размера в МБ.
- **Редактор команд:** подсказки фильтров, кодеков, форматов и ключей вашей сборки ffmpeg прямо при наборе; Tab подставляет первую.

## Ограничения

- Захват `ddagrab`, запись окна в Windows и установка плагинов frei0r в Windows проверены сборкой в CI и по исходникам ffmpeg, но не на реальном компьютере с Windows.
