<!-- Kadra v0.4.0 -->
Kadra 0.4 — субтитры, картинки, метаданные и ремонт файлов. Готовы этапы 1–4 из 6.

## Установка

- **Windows 10/11 (x64):** распакуйте `kadra-v0.4.0-windows-x64.zip` и запустите `kadra.exe`.
- **Linux (x64):** распакуйте `kadra-v0.4.0-linux-x64.tar.gz` и запустите `kadra`; нужны GTK 3 и libmpv (`sudo apt install libgtk-3-0 libmpv2`).

ffmpeg и yt-dlp устанавливаются из раздела «Компоненты» при первом запуске (с проверкой SHA-256). Настройки и очередь из 0.3 сохраняются.

## Новое

**Субтитры**
- Вшить в видео: дорожка из файла или отдельный SRT/ASS/VTT; размер, цвет, подложка, положение, отступ, кодировка (CP1251 и др.); предпросмотр кадра и A/B-сравнение.
- Дорожки: добавить с языком, названием и флагами «по умолчанию» / «принудительные», удалить, извлечь в SRT/ASS/WebVTT — без перекодирования видео.
- Конвертация файлов субтитров SRT ↔ ASS ↔ WebVTT со сдвигом, пересчётом частоты кадров (25 ↔ 23,976) и сменой кодировки.

**Картинки**
- Кадры: один, лучший, через интервал, N штук, на смене сцен — в PNG, JPEG, WebP, AVIF или JPEG XL.
- Раскадровка с временем на миниатюрах.
- Слайд-шоу с переходами, плавным наездом и музыкой (можно подогнать под длину трека).
- Аудио → видео для YouTube: обложка из файла, своя картинка или цвет, размытый фон, волна.
- Визуализаторы звука: волна, спектр, вектороскоп, ноты.
- Конвертация изображений с ограничением размера и удалением EXIF/GPS.

**Метаданные**
- Теги (включая свои и языки дорожек), обложка (добавить, заменить, удалить, сохранить), главы с вставкой и копированием списка в формате описания YouTube.

**Ремонт**
- Пересборка с восстановлением временных меток, сдвиг звука, перекодирование с постоянной частотой кадров для записей, где звук постепенно уезжает.
- Faststart для MP4/MOV с проверкой, нужен ли он файлу.

## Исправления

- «Аудио → видео» использует встроенную обложку (раньше подставлялся цветной фон).
- Нормализация в аудиоредакторе точно попадает в целевой пик при смещении постоянной составляющей.

## Известные ограничения

- Распознавание речи — только со сборкой ffmpeg, где есть фильтр `whisper` (на Windows — полная сборка gyan.dev).
- Нет установщика, подписи exe и автообновления — Windows SmartScreen может предупредить при первом запуске.
