<!-- Kadra v1.0.1 -->
Исправления загрузки видео и подвисаний.

## Установка

- **Windows 10/11 (x64):** установщик `kadra-v1.0.1-windows-x64-setup.exe` или переносная версия `kadra-v1.0.1-windows-x64.zip`.
- **Linux (x64):** `kadra-v1.0.1-linux-x86_64.AppImage` или `kadra-v1.0.1-linux-x64.tar.gz`.

Kadra 1.0.0 найдёт это обновление сама (в течение 20 секунд после запуска или в Настройках → «Проверить»).

## Исправлено

- **YouTube:** анализ ссылки не передавал yt-dlp движок JavaScript (Deno), из-за чего YouTube не отдавал форматы и загрузка не работала. Если Deno не установлен, на странице «Загрузки» теперь заметное предупреждение с кнопкой «Установить».
- **Зависания:** ответ yt-dlp для плейлистов и роликов с множеством форматов (несколько мегабайт) разбирался в потоке интерфейса — окно замирало. Теперь разбор идёт в фоне.
- **Лаги во время задач:** всё окно перерисовывалось при каждом обновлении прогресса каждой задачи; теперь обновляется только счётчик очереди.
- Окно при запуске на Windows больше не ждёт настройки системных уведомлений.
